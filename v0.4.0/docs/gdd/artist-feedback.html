Artist feedback: plan and checklist ​

Every bullet of the artist's feedback is one line here. Status: [ ] open, [x] done and checked, [?] needs a decision from the owner.

R. Rename the game to "Fishy Find" (decided by the owner) ​

  • [x] R1 New logo "FISHY FIND", made with ChatGPT (the owner allowed it for the logo, in place of the CLAUDE.md "no ChatGPT" rule), transparent background (solid key colour, then keyed out with the existing script)
  • [x] R2 Player-visible name: page title, loading screen, docs title, landing page, pop-ups that say "Spot A Fish"
  • [x] R3 NOT renamed (would break links / saves): repo and Pages URL spot-a-fish, save key findfish_v1, code identifiers. Renaming the repo is the owner's call.

A. Game logo / loading screen (the new logo covers A1 to A3) ​

  • [x] A1 The second word (FIND): yellow-orange instead of pink-orange
  • [x] A2 Fewer sparkle stars around the logo (too busy)
  • [x] A3 The fish inside the magnifier is not pretty: draw a nicer one in the new logo
  • [?] A4 No second fish under the loading bar: use an icon instead [?] which icon
  • [x] A5 Loading bar fill brighter (not the same colour as the frame), darker backing layer under the frame, text on top of the bar

B. Icons: Level, Pause, Booster ​

  • [x] B1 Icons too big, they hide the button's bubble: shrink icons (or drop the bubble if not needed)
  • [x] B2 Vibration icon in Settings is broken: check and fix

C. Booster FTUE ​

  • [x] C1 Centre the text in its frame
  • [x] C2 Fix the bubble's pointer arrow

D. Feature screen ​

  • [x] D1 No effect on "NEW FEATURE" and the feature name
  • [x] D2 Remove the text frame (text only)
  • [x] D3 A "Continue" button instead of the line "Tap to continue"

E. Theme background every 10 levels ​

  • [x] E1 Two of the themes look the same: give each of the 6 a clearly different colour
  • [x] E2 A clear change when the theme switches (so the player feels it)

F. Hard / Super Hard ​

  • [x] F1 "LEVEL 10" and "LEVEL 20": the digits overlap
  • [x] F2 Level number too pale: white text with stroke, badge circle purple (Hard) / red (Super Hard)

G. Text style (all popups and titles) ​

  • [x] G1 Colours were pastel with a white stroke: make them vivid, add a thin dark (brown-black or blue-black) stroke
  • [x] G2 White text gets a thick dark stroke
  • [x] G3 One rule for the black shadow on text (Settings pop-ups differ from the rest)
  • [x] G4 No wave / ripple effect on text

H. Target tank and Backup slot ​

  • [x] H1 Target tank: remove the plants at the sides
  • [x] H2 Backup: remove the light shining down
  • [x] H3 Both: render more 3D, in the style of the big tank below
  • [x] H4 The background picture behind them looks flat / 2D

I. Wrap-up ​

  • [ ] I1 Check each item on a phone-size screen and a wide screen
  • [ ] I2 Changelog and release
